# React Prayer Times Package

Create a Vite, React, and TypeScript demo for the archived `react-prayer-times` package.

## Features

1. The demo focuses only on this package version of the Prayer Times Component family.
2. The demo explains that this repo was the reusable component package, not a complete prayer-times app.
3. The demo shows the original prop-driven table behavior with toggles for the optional prayer rows, including the later `jumuah` prop.
4. The demo includes a guided tooltip tour that explains the package role, prop controls, rendered table, and source shape without switching to other versions.
